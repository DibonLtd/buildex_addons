ZKTeco Biometric Attendance Integration
======================================

Odoo Zkteco Device Integration enables seamless connection of a biometric attendance machine
with Odoo. It allows syncs check-in, check-out, and break logs into the system.

Module Changelog
================

**1.0.0 May 2025**
~~~~~~~~~~

1. Manage all Machine users.
2. Added Real-time attendance sync .
3. Attendance data is fetched automatically every 10 minutes
4. Manage Employee Breaks.
5. Easily Enroll and Remove Employees.
6. Manage multiple punch state (check-in, check-out, break-in and break-out)
